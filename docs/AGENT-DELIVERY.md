# Criar e receber um projeto

Seleciona um projeto, escreve o pedido e escolhe Automático ou Criar e entregar ZIP. O modelo revê o plano e pode corrigir os testes propostos antes da tua autorização. Revê as alterações completas, o modelo e os comandos de teste apresentados; confirma para começar. O agente cria os ficheiros, pede uma revisão ao modelo local, executa os testes autorizados sem rede e corrige falhas até ao limite de tentativas. Os testes aprovados ficam protegidos contra alterações do agente. Comandos novos exigem nova autorização.

Quando surgir Projeto pronto para guardar, usa Guardar ZIP do projeto e escolhe a pasta. Inclui os ficheiros e NEXO-RELATORIO.json com os testes e o inventário. O ZIP corresponde à versão validada, mesmo que edites o projeto depois. .env, chaves e pastas de dependências são excluídos por nome; verifica o conteúdo antes de o partilhares. Limite de ZIP: 32 MB.

Só conversar responde sem iniciar este fluxo. O executor atual suporta testes Node, não execução arbitrária de Python, Lua, jogos ou aplicações externas. Um modelo pode falhar a resposta estruturada; nesse caso a sessão apresenta o erro sem produzir uma entrega validada. Revisão pelo modelo e testes aprovados não garantem correção completa.
